# Propuestas de Mantenimiento para el Sistema de Pedidos de una Cafetería Universitaria

## 1. Mantenimiento Correctivo
Acciones destinadas a corregir errores detectados durante la operación del sistema.

- Solucionar fallos en el registro de pedidos, especialmente en horas de alta demanda.
- Reparar errores en la actualización del estado de los pedidos.
- Corregir inconsistencias en la visualización del menú (productos obsoletos o sin disponibilidad).
- Mejorar los mensajes de error para que sean más claros y útiles para el usuario.
- Revisar y corregir problemas relacionados con la autenticación de usuarios administrativos.

---

## 2. Mantenimiento Preventivo
Acciones para prevenir fallos futuros y mantener la estabilidad del sistema.

- Realizar respaldos periódicos de la base de datos.
- Limpiar o archivar pedidos antiguos para optimizar el rendimiento.
- Optimizar consultas a la base de datos para reducir tiempos de respuesta.
- Actualizar librerías y dependencias para evitar vulnerabilidades.
- Monitorear mensualmente el rendimiento del sistema y tiempos de respuesta.

---

## 3. Mantenimiento Perfectivo
Mejoras sobre las funcionalidades ya existentes.

- Agregar funciones de búsqueda y filtrado en el menú.
- Implementar notificaciones visuales o auditivas para indicar que un pedido está listo.
- Mejorar la interfaz gráfica para hacerla más accesible e intuitiva.
- Optimizar el panel de trabajo del personal separando vistas para cocina y caja.
- Incluir estadísticas básicas como ventas diarias y productos más solicitados.

---

## 4. Mantenimiento Evolutivo
Expansión del sistema añadiendo nuevas funcionalidades.

- Integrar métodos de pago digitales (tarjeta, billeteras electrónicas, sistemas universitarios).
- Desarrollar una aplicación móvil para pedidos remotos dentro del campus.
- Incorporar códigos QR para seguimiento y pago rápido.
- Añadir sistemas de promociones, combos o descuentos.
- Integrar el sistema con plataformas institucionales (por ejemplo, carnet universitario como método de pago).
